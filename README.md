# Tarea S1.05 - Java Utils

En esta tarea trabajaremos con distintas utilidades de Java que son fundamentales para el desarrollo de software en entornos reales. 

Aprenderás a gestionar archivos y directorios, a leer y escribir datos, a configurar tu código de forma flexible, e incluso a proteger información con técnicas básicas de cifrado.

Trabajaremos paso a paso, desde sencillas funcionalidades hasta operaciones más avanzadas, estructuradas en tres niveles. Además, todas las actividades tendrán que ser ejecutadas desde la línea de pedidos: esto te ayudará a entender mejor cómo funciona tu código fuera del editor, y te preparará para entornos profesionales donde dominar la terminal es clave.

## Durante esta tarea:

- Practicarás el uso de las librerías básicas de Java ( java.io, java.util, java.nio.file, etc.).
- Aprenderás a navegar por directorios , crear archivos , leer y escribir textos , ya trabajar con archivos de configuración .
- Conocerás el proceso de serialización y deserialización de objetos.
- Descubrirás cómo proteger datos con encriptación AES.
- Te asegurarás que tu código sea portable , utilizando rutas relativas y File.separator.
- Te familiarizarás con el proceso de compilación y ejecución manual de sus programas.

Recuerda que hay que seguir las buenas prácticas que establecimos en el Sprint 0 y que todo el trabajo debe realizarse en inglés, con una estructura clara, profesional y preparada para entregar.
